# АРАЛЫҚ · Соңғы түн. Бір топ. Сен.

Бірінші курсқа арналған қазақша чат-драма. Ойыншы өз аты мен кейіпкерін таңдап, алғашқы топтық жобаның соңғы түні мен қорғау таңын бастан өткізеді.

**Ойнау:** https://rusyeat.github.io/aralyq/

## Не бар?

6 эпизод, 18 тапсырма, 8 түрлі әрекет: диалогтағы таңдау, факт/болжам, қысқа үзіліс, хабарламалар басымдығы, деректерді ашу, сәйкестендіру, әрекет ретін өзгерту және хабарлама құрастыру. Таңдаулар кейіпкер жауаптарын, эпизод қорытындысын, сенімді, кернеуді және үш финалдың бірін өзгертеді.

Бір тапсырма — 100 XP-ге дейін. Ұтымды шешімдер тізбегі 25 XP-ге дейін комбо береді. Жеңіс: **1400 XP**, үш дағдының әрқайсысы кемі **50%**, топтағы сенім кемі **45%**. Қайта жауап беру ұпайды қайта есептейді; шексіз XP жинауға болмайды.

Музыка, хабарлама, таңдау және нәтиже дыбыстары жергілікті файлдардан ойнатылады. Баптауларда музыка, әсерлер, дауыс, дыбыс деңгейі және таймер бөлек басқарылады. Музыка ойыншы әрекетінен кейін басталады. Бет фонға кетсе, дыбыс пен ойын таймері кідіреді.

Таймер жауап құқығын немесе ұпайды алып қоймайды: кейіпкер қосымша хабарлама жібереді. Тыныш режимде таймер өшеді. Уақытты тоқтату, хабарламаларды бірден көрсету, пернетақтамен басқару және reduced-motion қолдауы бар.

## Оқу жоспары

- **1.8. Теріс эмоциялар және денсаулық:** күйді байқау, фактіні болжамнан ажырату, қолжетімділік пен демалысты жоспарлау.
- **2.5. Біздің өміріміздегі конфликтілер:** позиция мен мүдде, ресурстар, міндеттер, ескерту және қосалқы жоспар.
- **2.7. Тиімді коммуникация мен тұлғаның бәсекеге қабілеттілігінің байланысы:** белсенді тыңдау, Мен-хабарламасы, нақты кері байланыс, топтағы құрмет және бірлескен жұмыс.

Көрсеткіштер — сценарийдің шартты моделі; психологиялық диагностика немесе студенттің тұлғалық бағасы емес. Сабақтағы негізгі оқу дәлелі — студенттің таңдауының себебін түсіндіруі.

## Құрылымы

- `story.mjs` — диалогтар, кейіпкерлер, эпизодтар, тапсырмалар.
- `engine.mjs` — қадамдар, ұпай, финал, қайта оралу, сақталған прогресті тексеру.
- `play.mjs` — интерфейс, чаттың кезекпен келуі, таймер, мини-ойындар.
- `audio.mjs` — музыка, дыбыс әсерлері, қазақша дауыс және музыка деңгейін бәсеңдету.
- `game.css` — бейімделетін интерфейс пен анимациялар.
- `assets/voice/manifest.json` — дайын аудио клиптердің тізімі.

Жинақтау мен орындалу тәуелділіктері жоқ. ES modules үшін HTTP сервер керек. Python орнатылған ортада:

```sh
python -m http.server 4173
```

Немесе кез келген статикалық HTTP серверді қолданыңыз. Браузерден `http://localhost:4173` ашыңыз.

```sh
node --test engine.test.mjs
```

## Сақтау және деректер

Ойыншы аты, аватар, прогресс, баптау және рефлексия осы браузердің `localStorage` ішінде сақталады. Ойын серверге жауаптарды немесе рефлексияны жөнелтпейді. Тіркелу мен аналитика жоқ. Нәтижені UTF-8 мәтін файлына жүктеуге болады. Google Fonts қаріп жүктейді; хостинг өз стандартты сұрау журналдарын жүргізуі мүмкін.

## Дауыс

ElevenLabs аудиолары дайындалған кезде `assets/voice/manifest.json` толтырылады. Дауыс нақты адамнан клонданбайды. API кілті тек жергілікті көмекші жадында тұрады; репозиторийге кірмейді. Жарияланған ойын дайын аудиоларды ғана ойнатады, келушілерден кілт сұрамайды. Клип жоқ болса, мәтінмен ойнау қолжетімді.

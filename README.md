# АРАЛЫҚ · 1-курс психологиясы

**Ойнау:** https://rusyeat.github.io/aralyq/

Ойын фотодағы оқу жоспарының үш тақырыбын түсіндіру және жағдаятта қолдану үшін жасалған. Негізгі құрылым: **қысқа конспект → 6 қолдану жағдаяты → 3 білім сұрағы**. Барлығы 3 оқу бөлімі, 18 жағдаят және 9 білім сұрағы бар.

## Сабақпен байланысы

| Тақырып | Үйретілетін ұғымдар | Ойын тапсырмалары | Білім дәлелі |
| --- | --- | --- | --- |
| **1.8. Теріс эмоциялар және денсаулық** | Эмоцияның құрамдастары; дене, ой, әрекет; стресс пен денсаулық; өзін реттеу | Факт пен болжамды бөлу, дене белгісін тану, жүктеме мен демалысты жоспарлау | Дене белгісі, стресс туралы дәл тұжырым және өзін реттеуден 3 сұрақ |
| **2.5. Біздің өміріміздегі конфликтілер** | Тараптар мен мәселе; позиция мен мүдде; бес реттеу тәсілі; нақты келісім | Тараптарды тыңдау, мүддені сәйкестендіру, міндет пен қосалқы жоспар құру | Мүдде, ынтымақтастық және компромисстен 3 сұрақ |
| **2.7. Тиімді коммуникация мен тұлғаның бәсекеге қабілеттілігінің байланысы** | Белсенді тыңдау; Мен-хабарламасы; кері байланыс; кәсіби коммуникация | Хабарлама құрастыру, нақты әрекетті мінезге бағадан бөлу, кәсіби әрекетті келісу | Тыңдау, хабарлама құрылымы және кәсіби қолданудан 3 сұрақ |

Конспект әр тақырыптың алдында ашылады. Ойын кезінде «Сабақ» батырмасынан қайта оқуға болады. Әр жағдаятта тексерілетін ұғым көрсетіледі; жауаптан кейін сол ұғымның әрекетпен байланысы түсіндіріледі. Соңғы есепте әр білім сұрағы бойынша дәлел және қайталауды қажет ететін тұс беріледі.

## Білім тексеруі мен ұпай

Тақырыптан өту үшін 3 сұрақтың кемінде 2-еуін дұрыс жауаптау керек. Өтпесе, түсіндірме оқып, жауаптарын түзетеді. Таймер білім сұрақтарында жүрмейді.

- Дұрыс білім жауабы — 100 XP; барлығы 900 білім XP-ге дейін.
- Қолдану жағдаяты — 100 XP-ге дейін; ұтымды қолданулар тізбегі 25 XP-ге дейін қосымша береді.
- Қайта жауап беру бұрынғы ұпайды алмастырады; ұпайды шексіз көбейту мүмкін емес.
- Жеңіс: 2000 XP, үш білім тексеруінен де өту, әр қолдану дағдысы кемінде 50% және топтағы сенім кемінде 45%.

Білім нәтижесі мен оқиғадағы сенім/кернеу — бөлек көрсеткіштер. Бұл психологиялық диагностика немесе тұлғалық баға емес. Сабақтағы талқылауда студент өз шешімінің себебін түсіндіріп, жаңа жағдайдан мысал келтіреді.

## Оқиға және дыбыс

Кейіпкер өз атымен алғашқы топтық жобаның соңғы түні мен қорғау таңын бастан өткізеді. Сюжет — ұғымдарды қолданатын орта. Үш түрлі финал, музыка, чат дыбыстары және сегіз қазақша дауыс клипі бар: кіріспе, алты эпизод және финал. Тыңдауды тоқтатып, сол жерден жалғастыруға болады; дауыс оқылғанда музыка бәсеңдейді. Бет фонға кетсе, дыбыс пен таймер кідіреді.

## Техникалық құрылым

- `curriculum.mjs` — оқу мақсаттары, ұғымдар, дереккөздер және білім сұрақтары.
- `learning-ui.mjs`, `study.css` — сабақ, тексеру және білім нәтижесі экрандары.
- `story.mjs` — қолдану жағдаяттары мен диалогтар.
- `engine.mjs` — оқу кезеңдері, XP, өтудің шарттары және сақталған прогресті тексеру.
- `play.mjs`, `game.css` — ойын интерфейсі мен әрекеттер.
- `audio.mjs`, `assets/voice/manifest.json` — дайын аудиоларды ойнату.

Жинақтау немесе орындалу тәуелділіктері жоқ. Кез келген статикалық HTTP сервер арқылы ашылады. Python орнатылған болса:

```sh
python -m http.server 4173
```

Тексерулер:

```sh
node --test
```

GitHub Pages: **main → /(root)**, `.nojekyll`.

## Сақтау

Аты, аватары, прогресі, баптауы және рефлексиясы тек браузердің `localStorage` ішінде сақталады. Ойын жауаптарды серверге жібермейді, API кілт сұрамайды. Нәтижені UTF-8 мәтін файлына жүктеуге болады. Google Fonts қаріп жүктейді; хостинг стандартты сұрау журналдарын жүргізуі мүмкін.

Оқу құрылымы v3 кілтімен сақталады. Бұрынғы v2 прогресі бөлек қалады; жаңа нұсқа есім мен аватарды көшіріп, сабақтың басынан бастауды түсіндіреді.

# АРАЛЫҚ

Қазақ тіліндегі бірінші курсқа арналған психологиялық оқиға ойыны. Үш студенттің алғашқы топтық жобасы арқылы эмоцияны реттеу, конфликтідегі мүдделер және тиімді коммуникация үйретіледі.

## Оқу жоспары

- **1.8. Теріс эмоциялар және денсаулық** — күйді байқау, факт пен болжамды ажырату, демалыс пен әрекетті жоспарлау.
- **2.5. Біздің өміріміздегі конфликтілер** — позиция мен мүдде, өзара тиімді жоспар, нақты жауапкершілік.
- **2.7. Тиімді коммуникация мен тұлғаның бәсекеге қабілеттілігінің байланысы** — белсенді тыңдау, «Мен-хабарламасы», оқу және кәсіби ортаға көшіру.

## Ойнау

Үш тарау, тоғыз шешім, шамамен 10–15 минут. Әр шешімнен кейін салдары мен түсіндірмесі көрсетіледі. Факт/болжам карточкалары, үш тараптың деректері, хабарлама құрастыру бар. Алдыңғы таңдаулар келесі тараудың кіріспесіне және жинақталған ойын көрсеткіштеріне әсер етеді. Соңында дағдылар бойынша нәтиже, тоғыз шешімнің тарихы және жүктелетін рефлексия жазбасы беріледі.

Кернеу, сенім, айқындық және пайыздар — осы сценарийдің шартты оқу моделі. Психологиялық диагностикаға немесе студент тұлғасын бағалауға арналмаған.

## Іске қосу

Жинақтау және тәуелділік орнату қажет емес. ES modules үшін HTTP сервер қолданыңыз:

```sh
python -m http.server 4173
```

Браузерден `http://localhost:4173` ашыңыз. `index.html` файлын `file://` арқылы ашу модульдерге байланысты жұмыс істемеуі мүмкін.

Тексеру:

```sh
node --test game.test.mjs
```

## GitHub Pages

Репозиторийдің **Settings → Pages → Deploy from a branch → main → /(root)** параметрлері қолданылады. `.nojekyll` статикалық файлдарды тікелей жариялауға арналған. Барлық жергілікті сілтеме салыстырмалы, сондықтан жоба `/aralyq/` сияқты ішкі мекенжайда ашылады.

## Сабақта қолдану

2 минут — жағдаймен танысу; 10–12 минут — жеке немесе жұппен ойын; 5 минут — таңдауларды салыстыру; 1–2 минут — рефлексия. Студенттің өз таңдауын түсіндіруіне назар аударыңыз. Нәтиже пайызын тұлғалық баға ретінде қолданбаңыз.

## Деректер

Прогресс пен рефлексия тек браузердегі `localStorage` ішінде сақталады. Ойынның сервері, тіркелуі, талдау скрипті және рефлексияны жөнелту функциясы жоқ. «Басынан бастау» осы ойынның прогресін жаңартады. Google Fonts сыртқы қаріп жүктейді; желі болмаса жүйелік қаріп қолданылады. GitHub Pages хостингінің өзінің стандартты сұрау журналдары болуы мүмкін.
